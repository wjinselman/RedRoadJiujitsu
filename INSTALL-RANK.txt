RED ROAD - PENDING MEMBER RANK

This ZIP contains only the eight changed website/database files and this guide.
It has not been deployed and does not modify existing member records.

INSTALL ORDER
1. Back up the current website files and published Firestore rules.
2. Publish firestore.rules in Firebase's Firestore Rules editor FIRST.
   This is a database configuration file; uploading it to your website does
   not publish the rules. If your live rules have changed since the supplied
   source ZIP, merge these changes into those newer rules before publishing.
3. Upload the other ten files together to the website root, replacing the
   matching files and adding rank-model.js.
4. Refresh open member/admin pages so they load the updated portal script.

BEHAVIOR
- On phones, Join Now in the fixed quick-action bar and Try One Class Free
  in the main page both become Member Area for signed-in users and open the
  member portal instead. This uses the existing sign-in session only.
- New signups have official rank "Rank pending" and zero stripes.
- Signup and member profile include an optional self-reported rank field.
  This never changes the official belt or stripes.
- The existing owner/admin editor assigns official rank and keeps the
  assignment date, staff email, and change history.
- Existing member belts and stripes are preserved. Previously defaulted
  White Belt records must be corrected individually by an admin if needed.
- Coaches retain their existing permissions; this adds no new staff access.
- Cached older signup pages remain compatible during rollout and may still
  submit White Belt until refreshed.

CHECK AFTER INSTALL
Use a test member to complete signup and waiver, open the member portal,
save a self-reported rank, and confirm the official rank stays pending.
Assign the test member's belt/stripes in the admin editor and reopen the
member portal. Check an existing member still has their original rank.
