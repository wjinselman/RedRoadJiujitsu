Red Road - family dropdown and payment-link audit update

Upload all HTML, JavaScript and CSS files in this ZIP to the website root, replacing matching files. Refresh the dashboard after upload. Keep the other website files.

Firebase: FIREBASE/firestore.rules is the SAME rules update supplied with Simple Parent Links. If you already published that exact update in Firebase Console, no further rules change is needed. Otherwise publish it in Firestore Database > Rules. Uploading this file to GitHub does not publish Firebase rules. No SDK upgrade is required.

There are two different links:
1. Families > Parent / existing member > Save Parent Link links child profiles to a guardian for access/check-in. This lists existing members and parents who submitted child profiles, regardless of billing category. It does not create charges or change billing.
2. Members > Edit > Family Plan - Covered Member > Family payer links an existing roster member to the payer's payment coverage. This now recognizes both saved family-payer billing profiles AND older Family memberships with no separate billing profile. All member pages are loaded for this selector.

Payment fixes:
- Legacy Family parents no longer disappear because their billingProfiles record is absent.
- Selecting one saves its missing family-payer profile and the child's family-covered profile in one transaction. Existing Paid status is preserved; no payment date or receipt is invented. The covered member adds $0.
- Existing payer profiles, dates and receipts are preserved when linking another covered member.
- A saved Family program no longer blocks saving family billing.
- Explicit Adult or Kids billing profiles are not silently converted to $300 family billing. If a parent's saved billing is intentionally Adult/Kids, use Families for guardian linking; changing their billing plan is a separate admin decision.
